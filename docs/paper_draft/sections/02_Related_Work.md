# 2. Related Work

梳理 GNSS 多径检测、GNSS-SDR 处理、SAGE/最大似然类参数估计、车载 GNSS 测量和仰角条件统计建模相关研究，并明确本文定位。

## 已有可写内容

- 可围绕 GNSS 原始信号测量、导航辅助信号分解、路径级 delay/Doppler/power/coherence 参数提取组织文献综述。
- 可将本文方法定位为连接 GNSS-SDR tracking/NAV provenance、分阶段可靠性筛选和路径级数据库的工程化研究路线。
- 可以提出需要比较的相关方向，但不能把尚未完成的文献实验或基线比较写成结果。
