# 1. 引言

## 1.1 研究背景与动机

全球卫星导航系统（Global Navigation Satellite System, GNSS）已经广泛应用于车辆导航、智能交通、车路协同以及自动驾驶等场景。对于车辆平台而言，接收机需要在连续运动过程中，根据来自卫星的微弱扩频信号完成定位、测速和授时。因此，GNSS 接收信号的传播环境直接影响导航系统的可用性、稳定性和安全性。

车辆通常运行在具有明显空间变化的道路环境中。高层建筑、桥梁、水面、铁路设施、通信塔、植被以及山谷地形都可能对卫星信号产生反射、散射、遮挡和绕射。接收机天线处的观测信号因此可能同时包含直达路径和多个具有不同传播时延、频移、功率和相位的反射路径。随着车辆移动，接收机位置、卫星几何关系和周围反射体均持续变化，多径结构也随时间发生变化。

在这种动态车辆 GNSS 环境中，多径不应仅被视为一个简单的测量误差项。它实际上反映了电磁波在特定道路和周围环境中的传播过程，具有明显的时变性、场景依赖性和卫星仰角依赖性。若只记录定位性能的变化，而不分析形成该变化的传播路径，就难以解释不同环境中的多径差异，也难以建立能够用于仿真、评估和系统设计的统计信道描述。

## 1.2 现有 GNSS 多径表征方法的局限

现有 GNSS 多径分析通常依赖接收机层面的观测指标，例如载噪比（C/N0）、伪距残差和定位误差。C/N0 的变化可以反映信号质量下降或信号干扰增强；伪距残差可以表示观测量相对于导航解或估计模型的偏离；定位误差则可以直接描述多径等因素对最终导航性能的影响。这些指标对于识别性能退化、进行接收机监测和评价导航结果具有重要作用。

然而，接收机层面的指标主要描述多径造成的结果，而不能完整解释其传播机制。仅根据 C/N0、伪距残差或定位误差，通常无法直接获得各条传播路径的相对时延、路径功率以及 Doppler 特征，也难以区分具有不同传播机制但可能产生相似接收机误差的场景。换言之，这些指标能够回答“系统性能受到了多大影响”，但不能充分回答“哪些传播路径造成了这种影响”以及“这些路径如何随环境和车辆运动变化”。

因此，GNSS 多径研究需要从接收机级性能指标进一步扩展到路径级传播参数。只有获得路径级信息，才有可能将观测到的误差现象与具体的反射、散射和动态传播过程联系起来。

## 1.3 统计 GNSS 多径信道建模的必要性

无线通信领域通常使用统计信道模型描述传播环境对信号的整体影响。本文将以下参数作为候选统计特征集合，而不是预先确定的最终模型参数。核心候选包括功率延迟剖面（Power Delay Profile, PDP）、均方根时延扩展（RMS delay spread）、Doppler 扩展（Doppler spread）和 Ricean K 因子；扩展候选包括路径数量（number of paths）、平均超额时延（mean excess delay）、路径功率统计量（path power statistics）以及路径寿命或时间稳定性（path lifetime/temporal stability）。其中，PDP 可以表示不同传播时延处的接收功率分布，RMS delay spread 可以描述多径时延分散程度，Doppler spread 可以反映传播路径频移的离散程度，Ricean K 因子可以描述直达路径功率与散射或反射路径功率之间的相对关系。路径数量、平均超额时延、路径功率和路径时间稳定性则可以从数量、时延中心、功率结构和持续性角度补充传播描述。

将类似的信道建模思想用于动态 GNSS 场景，有助于从环境条件和卫星几何出发描述多径出现的概率、路径数量、时延特性、Doppler 特性、功率结构和时间稳定性。与孤立地报告某些多径事件相比，环境相关的统计模型更适合支持车辆 GNSS 接收机测试、传播仿真、算法评估和系统设计。上述参数目前构成用于多场景数据分析的 candidate parameter pool；最终进入统计模型的参数，将根据 production 数据中的统计稳定性、物理解释性、变量相关性和具体模型需求进一步筛选，而不是假定所有候选参数都会被保留。

但动态 GNSS 信道的统计建模具有特殊挑战。GNSS 信号功率较弱，且采用扩频体制；车辆运动会同时改变接收机位置、反射几何和相对 Doppler；不同道路环境中的反射体分布也可能在短时间内发生变化。此外，卫星仰角和方位角变化会改变直达路径与潜在反射路径的几何关系。因此，GNSS 多径统计模型需要建立在可靠的路径级观测基础上，并且需要保留场景、环境、车辆运动和卫星几何等条件信息。

## 1.4 基于 SAGE 的路径提取作用

SAGE（Space-Alternating Generalized Expectation-Maximization）是一类高分辨率参数估计方法，可以在多径信号模型下迭代估计不同传播分量的参数。对于本文关注的 GNSS 信号，SAGE 路径提取可以用于估计传播路径的 delay、Doppler、amplitude 和 phase 等参数，从而将接收机观测转换为可用于传播分析的路径级表示。

本文并不把 SAGE 本身作为最终研究目标，也不将算法实现复杂度作为论文的唯一贡献。SAGE 在本文中承担的是连接原始 GNSS 测量与统计信道模型的路径提取工具角色。具体而言，原始 IQ 数据首先经过 GNSS-SDR 解析，获得 tracking、navigation 和 trajectory 等支持信息；随后通过 NAV-aided SAGE pipeline 对有效时间窗口中的信号进行路径级估计；最后根据提取出的路径参数推导 PDP、RMS delay spread、Doppler spread 和 Ricean K 因子，并在环境条件下进行统计建模。

为保证路径结果具有可解释性，本文采用分阶段的可靠性处理思路。Stage0 构造有效 NAV symbol 和时间窗口母集，Stage1 进行导航辅助的初步扫描，Stage2 评估不同路径阶数的模型，Stage3 检查候选路径的持续性，Stage4 对联合时间窗口结果进行最终确认。该层级的作用是区分模型复杂度、持续性候选和最终确认路径，避免将单一高阶模型选择直接等同于物理多径事实。

## 1.5 本文工作与预期贡献

围绕 SAGE-based path extraction and statistical GNSS multipath channel modeling，本文拟开展以下工作：

1. 建立从原始 GNSS IQ、GNSS-SDR tracking/navigation support 到路径参数估计的端到端处理流程。该流程保留 raw 数据、GNSS-SDR 输出、NAV 信息、trajectory、卫星几何和 SAGE 各阶段结果之间的 provenance 关系，使路径提取过程能够被复核和重复执行。

2. 建立适用于动态车辆环境的可靠多径路径提取与验证流程。通过 Stage0–Stage4 的层级化处理，区分有效窗口、扫描候选、不同阶数模型、持续性候选和 Stage4 confirmed event/path，并为后续路径级统计提供明确的质量和标签语义。

3. 构建带环境标签的 10.23 MHz 车辆 GNSS 测量数据集。当前 scene metadata layer 覆盖 Urban、Mountain/Valley、Highway/Open 和 Special Reflective 等环境类别，并保存特殊条件、道路类型和人工确认的车辆速度等上下文信息。数据生产仍在进行中，本文不会在生产完成前声称最终数据集已经完整。

4. 基于路径级参数构建候选信道统计特征集合，包括 PDP、RMS delay spread、Doppler spread、Ricean K-factor、number of paths、mean excess delay、path power statistics 和 path lifetime/temporal stability，并在多场景数据基础上筛选适合的参数，进一步建立环境相关的 GNSS 多径统计信道模型。这一项是本文的目标性工作，必须在 path database、channel parameter database 和多场景数据 QA 完成后进行；当前仅确定候选参数池，不预先声称最终模型参数已经确定，也不声称所有候选参数都已验证或都会进入最终模型。

综上，本文的研究重点是利用高分辨率路径提取建立可解释的 GNSS 多径传播描述，并将其推进到环境条件化的统计信道建模，而不仅是报告接收机层面的性能退化或孤立的多径检测结果。
