# 汽车 GNSS 测试标准与文献清单

**用途：** 结题报告、车机信道可用性测试和后续复测方案参考
**整理日期：** 2026-09-15

## 1. 标准优先级

| 优先级 | 标准/文件 | 适用范围 | 在本项目中的用途 |
|---:|---|---|---|
| 1 | **GB/T 45086.1-2024**《车载定位系统技术要求及试验方法 第1部分：卫星定位》 | 车载卫星定位系统 | 主测试框架；用于组织功能、性能、鲁棒性、恢复和车辆环境测试 |
| 2 | **GB/T 27606-2020**《GNSS接收机数据自主交换格式》 | GNSS 接收机数据交换 | 统一 GNSS-SDR 观测、导航、PVT 等测试证据格式；不是车机合格门槛 |
| 3 | **JT/T 794-2019**《道路运输车辆卫星定位系统 车载终端技术要求》 | 道路运输车载终端 | 仅当被测设备属于道路运输车载终端时补充采用 |
| 3 | **JT/T 1253-2019**《道路运输车辆卫星定位系统 车载终端检测方法》 | 道路运输车载终端检测 | 补充检测项目和记录方法；不替代乘用车车机标准 |
| 4 | **GB/T 46369-2025**《北斗导航型接收终端性能要求及测试方法》 | 北斗导航型接收终端 | 若测试设备/信号支持北斗，可作为接收机层补充参考；不是专门的汽车标准 |
| 5 | **IS-GPS-200N** | GPS L1/L2 空间段与用户段接口 | 冻结 GPS L1 C/A 信号和导航数据接口；不是汽车接收机合格标准 |

## 2. 不建议作为当前合规依据的旧 GPS 标准

国家标准信息公共服务平台显示，以下标准已废止：

- SJ/T 11420-2010《GPS导航型接收设备通用规范》；
- SJ/T 11428-2010《GPS接收机OEM板性能要求及测试方法》；
- SJ/T 11426-2010《GPS接收机射频模块性能要求及测试方法》。

例如 [SJ/T 11420-2010 官方状态页](https://std.samr.gov.cn/hb/search/stdHBDetailed?id=8B1827F1BB50BB19E05397BE0A0AB44A) 已显示“废止”。这些文件最多作为历史背景，不应作为当前汽车车机测试的主标准。

## 3. 中文优先文献

1. **杨伟、赵昀、寇艳红、黄智刚：《GPS多径信号建模及接收机测试评估》**，北京航空航天大学学报，2009，35(5):551-554。该文建立镜面反射 GPS 多径模型，并用软件接收机考察多径对伪距测量精度的影响，适合作为“信号级生成—接收机验证”的方法参考。[论文页面](https://bhxb.buaa.edu.cn/bhzk/cn/article/id/8865)

2. **寇艳红、常青、张其善：《高动态GPS模拟器闭环测试系统结构与软件设计》**，北京航空航天大学学报，2004，30(06):534-538。该文讨论 GPS 模拟器、数据采集接收机和闭环性能测试系统，可参考测试链路组织方式。[论文页面](https://bhxb.buaa.edu.cn/bhzk/article/id/10464)

3. **贾琼琼、郭琪琪、李伟鹏、陈泓锦：《基于信号质量监测的高效鲁棒的多结构GNSS接收机》**，交通运输工程学报，2025，25(1):132-144。该文涉及多径、弱信号、遮挡、信号质量监测和定位输出，适合作为测试指标设计的补充参考。[论文页面](https://transport.chd.edu.cn/article/doi/10.19818/j.cnki.1671-1637.2025.01.009)

## 4. 汽车多径和记录回放参考

- **S. Khanafseh et al., “GNSS Multipath Error Modeling for Automotive Applications,” ION GNSS+, 2018.** 讨论汽车动态场景中的多径误差、误差统计和时间相关性。[论文页面](https://www.ion.org/publications/abstract.cfm?articleID=16107)
- **“Scalable multipath detection from standard GNSS correlators using multifrequency diversity,” Nature, 2026.** 说明 C/N0 对严重衰减/遮挡有用，但单独不足以完成多径判定，支持本项目同时记录车机、PVT、跟踪和失锁层证据。[论文页面](https://www.nature.com/articles/s44459-026-00064-9)

## 5. 对本项目最实用的测试记录字段

每次暗室回放建议至少记录：

- 场景、质量状态、参数表和 hash；
- 回放起止时间、是否重启车机、是否从头播放；
- 车机位置图标、GPS 时间、精度字段和恢复时间；
- GNSS-SDR 首次定位时间、PVT 有效历元比例、最长无定位区间、重新捕获时间；
- 可用/使用卫星数、C/N0、tracking lock-loss 事件；
- 若要评价绝对位置误差，还需要已知轨迹或独立真值，不能把 GNSS-SDR 单独当作绝对真值。

## 6. 可用信道筛选逻辑

| 车机 | GNSS-SDR | 工程结论 |
|---|---|---|
| 能持续定位 | 能持续定位 | 信道进入可用候选 |
| 不能定位 | 能持续定位 | 不立即废弃；优先做另一辆车复测和车机恢复链路诊断 |
| 不能定位 | 也不能持续定位 | 在 clean 基线和测试链正常的前提下，当前信道从动态定位候选中剔除 |
| 不能定位 | GNSS-SDR 证据不完整 | 结论为 inconclusive，不判定信道或车机责任 |

上述逻辑是项目工程筛选规则，不是对 GB/T 45086.1-2024 的完整符合性声明。具体标准门限必须以正式标准全文和预先冻结的测试条件为准。
