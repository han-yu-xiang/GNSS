# GB/T 45086.1-2024 与本项目关系说明

**材料用途：** 结题汇报中的标准对照说明
**整理日期：** 2026-09-15

## 1. 标准基本信息

GB/T 45086.1-2024 的名称为《车载定位系统技术要求及试验方法 第1部分：卫星定位》，英文名称为 *Technical requirements and test methods for on-board positioning system—Part 1: Satellite positioning*。国家标准信息公共服务平台显示，该标准为现行推荐性国家标准，发布日期为 2024-11-28，实施日期为 2025-06-01。

- 官方标准信息页：<https://std.samr.gov.cn/gb/search/gbDetailed?id=28045D84DA059055E06397BE0A0A7C5C>
- 官方解读页：<https://cc.sacinfo.org.cn/course?id=8a6dd871917d1d720193fbb7d8795b6d>

官方解读涉及车载定位系统的术语、功能、性能、鲁棒性、射频信号协调、车辆环境要求和关键试验方法。因此，它适合作为本项目“车机是否能够在规定信号条件下持续工作”的测试框架参考。

## 2. 本项目可以怎样定位

建议汇报表述为：

> 本项目面向 GB/T 45086.1-2024 所涉及的车载卫星定位测试需求，构建了可重复的 GNSS 场景与信道参数仿真子系统，重点支持动态轨迹条件下的 LOS/NLOS、多径、相对时延、相对多普勒、相对幅度、相对相位、功率衰减以及信号中断/恢复等传播压力场景，并通过车机与 GNSS-SDR 双链路进行可用性筛选。

更克制的工程边界是：

- 当前成果是**标准相关的信号/信道场景输入与测试子系统**，不是已经完成全部条款验证的整车暗室 OTA 合规系统；
- 当前暗室参数生成器输出的是 canonical path table，已完成环境、仰角上下文、质量状态和 Rain effect layer 的经验化组合；
- 绝对 RF 输入功率尚未完成硬件端校准，因此不能仅凭相对功率参数宣称已完成灵敏度或 1 dB 精度的标准符合性测试；
- 当前单路 RF/单天线架构不能等同于多天线 OTA 方位角入射仿真；软件中的卫星几何字段也不能直接表述为实际空间入射方向；
- 电离层、对流层、整车 OTA 多天线矩阵和标准条款级通过判定不应在结题材料中写成已完成能力，除非有独立 artifact 和标准全文条款核对证据。

## 3. 与本项目现有资产的对应关系

| 标准相关测试关注点 | 本项目当前对应资产 | 当前判断 |
|---|---|---|
| 可重复的卫星/信道输入 | `dataset_generation_logs/channel_modeling/0828darkroomPar` 与 Rain effect layer 输出 | 已建立参数表生成资产 |
| 动态轨迹场景 | 16 组合的 Low/Mid/High canonical path table；0913 GNSS-SDR 自发自收结果 | 已具备场景输入和独立接收验证材料 |
| 多径/传播压力场景 | 环境×仰角路径分布、主径增益/衰落、固定 NLOS 槽位、Rain Stage3 effect layer | 已实现，属于经验模型，带限制 |
| 失锁与恢复观测 | `DARKROOM_RX_0913_ALL8_SIGNAL_QUALITY_REPORT_CN.md` 及对应 GNSS-SDR 输出 | 已有诊断结果，尚非车辆标准符合性结论 |
| 接收机定位结果 | 车机界面人工观察 + GNSS-SDR NMEA/PVT | 双链路测试方法已规划 |
| 绝对功率/灵敏度门限 | 当前无绝对 RF 功率校准 artifact | 未建立 |
| 多天线 OTA 入射方向 | 当前材料未形成多 RF/多天线测试证据 | 未建立 |

## 4. 对附件中既有分析的使用边界

附件分析中关于“标准条款 6.2.1”、功率步进、重捕获测试和附录场景的具体解释，可作为结题汇报的**待全文核对工作底稿**。由于当前工程目录没有保存标准全文，本材料不把这些条款细节直接写成已验证事实。

在正式汇报中应区分：

1. “与标准关注方向一致”；
2. “本项目已经实现并验证的子系统功能”；
3. “按照标准全文逐条执行后才能判定的符合性结果”。

## 5. 推荐的一句话结论

> 本项目已经形成面向车载卫星定位测试的可重复 GNSS 信道场景与参数生成子系统，可作为 GB/T 45086.1-2024 相关测试链中的信号/信道输入和定位可用性筛选模块；当前不宣称完整标准符合性，下一步以双车辆、GNSS-SDR 对照和绝对功率校准完善可用信道筛选。
