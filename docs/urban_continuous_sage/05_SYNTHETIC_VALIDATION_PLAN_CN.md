# 05 双采样率合成 IQ 真值验证计划

**本文件规定未来验证实验；本轮没有生成合成 IQ、运行 SAGE 或处理真实数据。** 先冻结信号模型与评价规则，再开展算法实现。真实 Urban 数据只有接收机辅助结果，没有独立路径级真值，不能代替本计划。

## 1. 信号发生器与真值

生成 GPS L1 C/A PRN 的 1023-chip、1 ms 重复 Gold 码，逐 20 ms 生成已知 ±1 NAV 符号及可控翻转；用实际 Fs=10,230,000 和 20,460,000 Hz 采样同一连续时间信号。每路径按带时间的 $\tau_\ell(t),\nu_\ell(t),\alpha_\ell(t)$ 合成复基带，包含公共码相位、公共频率、相对 fading、复相位、前端滤波、量化和噪声。初始受控实验用已知滤波/白复噪声；稳健性实验加入带宽变化、相关噪声、时钟漂移、载波/码辅助误差和错误/缺失 NAV 符号。保存真实路径 ID、出生/消失时刻、LOS/NLOS 标签、可观测掩码与真实相位。

发生器的文件封装分别测试**纯载荷**与符合本机实测格式的 512 字节头 + 小端交织 int16 载荷；头字段编码 Fs 和名义中心频率，明确真值 payload index 与 raw-file index 差 128。任何未在实测确认的 I/Q 正负或 IF 假设都应做成可切换、标注的生成参数，不以合成“通过”偷换真实前端校准。

每个实验记录随机种子、滤波响应、Fs、C/N0、路径参数轨迹、导航比特、真值文件版本和计算预算。用于调门限的开发集与最终报告的留出种子/参数组合分离，不能在留出集反复挑最佳配置。

## 2. 场景矩阵与覆盖目的

下表的取值是**测试网格**，不是检测通过门限。C/N0 网格 30/35/40/45/50 dB-Hz 横跨实测代表 tracking 的约 39–49 dB-Hz 并留低信号压力端。延迟以 chip 表示以跨 Fs 一致；0.05–0.1 chip 接近本机采样间隔，刻意测试近径不可辨与前端带宽限制。采用分层/成对组合，避免把所有维度盲目做完整笛卡儿积。

| 因素 | 受控组合 | 要检验的失败方式 |
| --- | --- | --- |
| 路径数 | 1、2、3–4，含无多径仅参考径 | 虚警、过拟合、阶数选择 |
| 超额延迟 | 0.05、0.1、0.25、1.0 chip，含两径间隔更近的压力例 | 近径、off-grid 偏差、分离失败 |
| 相对功率 | −3、−10、−20 dB，含渐强/渐弱 | 弱径漏检、强径污染 |
| 相对 Doppler | 0、±5、±20、±40 Hz，含斜变与跳变 | 历元相位歧义、Doppler/运动混叠 |
| 复相位 | 0、π/2、π 及连续随机起相 | 相消/相长、I/Q 符号 |
| C/N0 | 30、35、40、45、50 dB-Hz | 误报/漏报与不确定度校准 |
| 时间事件 | 突然出生/终止、缓慢出现/消失、短漏检、重新出现 | 确认延迟、终止延迟、错误重捕获 |
| 关联 | 两路径延迟接近、交叉、同时出生 | ID 交换、碎片化、全局匹配 |
| 数据支持 | NAV 翻转、未知符号、GPS 锚点局部缺失、仰角缺口 | 不允许跨缺口编造连续轨迹 |
| Fs/历元 | 两种 Fs × 10/20/40 ms | 原生速率、积分偏差与成本 |
| 模型失配 | 前端带宽/ACF、相关噪声、时钟漂移、相位重置 | 相关器与直接 IQ 差异 |

## 3. 公平基线与主要指标

A：独立窗口复 IQ SAGE（相同单历元目标函数，不用跨历元先验）。B：在 A 上加入状态预测、全局关联及生灭的动态 SAGE。C：若满足信息保留条件，再比较高密度复相关器动态 SAGE。三者使用相同的生成 IQ、NAV/码辅助、路径搜索区和预注册模型阶数预算；将“更大计算量带来的改善”和“时间模型带来的改善”分开报告。每种 Fs、每种历元长度分别汇报，不把两种 Fs 的样本数直接合并。

| 指标 | 计算方式与注意事项 |
| --- | --- |
| 时延、相对 Doppler、相对功率误差 | 在正确 ID/匹配的检测上给 RMSE、中位绝对误差和偏差；漏检单列，避免幸存者偏差 |
| 路径数正确率 | 每历元 $L$ 精确率、过/欠估率，含纯单路径虚警 |
| 检出/虚警/漏检 | 以真值存在窗口和可观测掩码为分母，区分路径事件与窗口事件 |
| 路径 ID 交换 | 每条真轨迹跨历元的错误指派次数/时间；交叉场景单列 |
| 轨迹碎片化 | 一条真轨迹对应的预测轨迹段数及 gap 分布 |
| 出生/终止延迟 | 对真事件的时间误差，另报因漏检造成的区间不确定 |
| 观测寿命/物理寿命 | 首末有效观测区间与真值对比；对左右删失使用区间/生存指标，不把缺口内路径强推为存在 |
| 不确定度 | 置信区间覆盖率、innovation 分布、协方差过/低自信 |
| 成本 | 每历元运行时间 p50/p95、总耗时、峰值 RAM、bank 形成与 SAGE 迭代分别计时 |

由生成器保存真值，先按时间与参数门限做一次**不使用估计 ID 的最小成本匹配**，再评估 ID 连续性；不能先按估计 ID 挑选有利配对。匹配距离、允许的真值不可分区和误差单位在开发集确定后冻结。近径不可辨区域可报告“合并检测”，不能靠强行分开提高计数。

## 4. 模型阶数、关联与验证门限

旧 IQ BIC 若把 2N 个实分量全视作独立，会在滤波/过采样下误估惩罚。验证中并列比较：直接 IQ 的残差白化诊断、重建 bank 的协方差/有效秩、按码周期或历元分块的留出似然，以及无多径真值下的虚警分布。先选定可接受的虚警风险和最小可辨路径效应，再由开发集设置阶数、关联门、Candidate→Tentative→Confirmed 及 Missing→Terminated 的规则。不得事后为每个录制单独调门槛以“通过”。

**V1 供审阅的暂定 go/no-go 条件**如下。数值来自已知离散时间分辨、86 个严格片段的统计污染风险及相同真值的成对比较；不是从 Urban 无真值数据反推的“最优”门限。开发集只用于配置搜索和误警校准，以下决策在留出集执行。

| 关口 | 暂定通过条件 | 依据/失败解释 |
| --- | --- | --- |
| 双 Fs 输入正确性 | 两种采样率、纯载荷/512 字节头两封装均精确恢复已知样本序列与 NAV 边界；raw 与 payload 坐标差恰为 128，无 off-by-one | 合成文件具有字节级真值；输入错位则任何路径结论无意义 |
| 无噪声、可分离单径 | 不产生额外路径；时延/Doppler 误差不超过最终细搜索步长的一半，或连续优化器的已验证数值容差 | 理想可辨条件下剩余误差只能来自搜索离散化/数值求解；近径不可辨样本另列 |
| 明显生灭事件 | 在高 C/N0、真路径可分的构造情形，首次/末次有效窗与真值事件相差不超过一个实际历元；无噪声漏检/假确认数为零 | 事件落入历元内部时，时间分辨上限是一个历元，不能声称更精确 |
| 确认假路径预算 | 在按 86 段等规模构造的纯单径/无径噪声实验，确认假路径**期望数 ≤1/86 每段**，即整个 86 段规模期望不超过 1；报告该率的 95% 上置信界 | 一条虚构长路径即可污染寿命尾部；这是可审议的研究风险预算，不是 GPS 常数 |
| 动态 B 相对独立 A | 对两种 Fs 的可辨交叉/漏检/生灭留出场景，ID 交换率和轨迹碎片化至少一项的成对 95% 置信区间上界 <0，另一项上界 ≤0；寿命区间误差上界 <0；标称场景时延/Doppler/功率 RMSE、虚警和漏检差异的上界 ≤0 | 要证明动态层带来身份/寿命增益，且未用参数精度和检测代价换取表面平滑；若太严格，报告未通过而非事后放宽 |
| 不确定度校准 | 声称的 90% 路径参数区间，在独立留出真值上的实际覆盖率之 95% 二项置信区间包含 90% | 覆盖率必须与报告的置信水平相称，防止过度自信 |
| 相关器 C 升为主计算路径 | 精确张成/白噪声合成例的加权目标差不超过已验证求解器数值容差；在两种 Fs 的近径、弱径、NAV 翻转及失配留出例，相对 B 的误差/漏检/ID 指标成对 95% 上界 ≤0，且运行时间比 B/C 的 95% 下界 >1、峰值内存不高于 B | 先证信息/科学结果不丢，再证实际加速；失败则只保留 C 作可选对照 |

这里“误差差异”均按 B−A 或 C−B 定义，越低越好；检出率用 A−B 使方向一致。相等界可由预注册非劣界替代，但非劣界须先由 GPS C/A 的时延/运动科学容差和接收机输入不确定度推导，并经负责人批准，不能在留出结果后选。对于真实录制的离线研究，本轮不臆造一个硬件耗时门限；第 1 次实现必须实测每历元 p50/p95 和按 978.483 PRN/channel 秒外推的总时间，由负责人以可用计算资源决定是否具备批处理条件。C 的采用则已有明确“确实加速且不牺牲指标”门槛。

## 5. 后续实测输入检查与实施顺序

在任何真实批量分析前，两种 Fs 各选一段已有较长联合支持区间，只读核对：头部索引转换、原始复 IQ 与接收机 Prompt 的相关峰及相位/共轭方向、C/A 码序列与分数码相位、NAV 符号边界、公共 Doppler 符号、GPS 时间拟合和 GSV 支撑历元。特别检查 UVS-0034/UVS-0072 的末端一采样边界。该有限对照是**输入验证**，不是多径生产估计。

批准后的实现顺序建议为：(1) 双 Fs 文件/时间/码/NAV 输入接口与样本级对照；(2) 独立合成 IQ 发生器和 A 基线；(3) B 的最小状态、SAGE、路径关联及生灭；(4) C 的相关器加速与统计等效测试；(5) 保留真值验收，再以少量真实片段做只读探索。任一步验证失败都保留原始证据并修订模型，不用后续平滑掩盖前一步误差。
