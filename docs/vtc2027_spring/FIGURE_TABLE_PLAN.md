## Figure/table QA rules

- Every number must have a source path and QA status.
- Do not use G12 in a figure or table until the evidence matrix selects the bounded claim; its output is complete and QA-passed, but it is not automatically a core VTC result.
- Do not use raw-coarse/sampling outputs as production path data.
- Preserve Stage4 confirmation semantics and distinguish event-level and path-level fields.
- Do not imply that an environment label predicts multipath occurrence.
