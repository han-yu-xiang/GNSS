# Path-Level Channel Modeling Review

This isolated namespace contains the author-review outputs for the modeling quantities supported by the current retained path-observation population.

The planned primary inputs are the path excess delay, absolute relative Doppler, and path-relative power fields. The primary environment classes are Urban and Mountain/Valley, with LOW, MID, and HIGH elevation bands.

This review does not load raw IQ or MAT signal payloads, run MATLAB/SAGE, construct a full CIR PDP, fit a received fading envelope, calculate snapshot-lag correlation, or modify the formal VTC manuscript. All model outputs remain conditional on the retained path-observation population and are not a complete stochastic channel model.

The input audit and all later figures, tables, model files, and QA records will be stored below this directory.
