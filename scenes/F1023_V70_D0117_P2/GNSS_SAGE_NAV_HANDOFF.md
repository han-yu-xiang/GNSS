## 1. 项目最终目标

处理 RF-Catcher 采集的 GPS L1 C/A 原始 IQ 数据，对每颗满足条件的卫星进行 SAGE 多径参数估计，然后按照场景和卫星仰角分区建立传统统计信道模型。

固定仰角分区为：

| 分区 | 仰角范围 |
|---|---:|
| LOW | 0°–30° |
| MID | 30°–60° |
| HIGH | 60°–90° |

最终建模单元不是“单颗卫星”，而是：

```text
采集场景 × 仰角分区 × 该分区内所有合格卫星的可靠多径样本
```

不同场景、不同仰角分区分别拟合模型，不应直接混合。

## 6. 新脚本的完整算法路线

在这里，`L` 表示总路径数，真正的多径数为 `L-1`。例如 `L=3` 表示1条最早到达路径和2条附加多径。

| 阶段 | 输入 | 处理 | 主要输出/判定 |
|---|---|---|---|
| Stage 0 | G06 telemetry、tracking、NMEA | 校验 PRN、`nav_symbol`、采样边界、TOW连续性、C/N0和锁定；建立完整40 ms窗口目录 | 有效导航符号表、40 ms窗口表 |
| Doppler sign | 若干有效窗口 | 比较 GNSS-SDR 多普勒正负号与原始 IQ 的相关峰 | 自动选择 `+1` 或 `-1` |
| Stage 1 | 全部有效40 ms窗口 | 按两个20 ms导航符号做符号擦除；估计主径；从残差延迟-多普勒面提取最多3个独立峰 | 快速扫描表、候选窗口 |
| Stage 2 | Stage 1候选及其邻窗 | 0.01 chip分数时延 SAGE，依次拟合 `L=1..4`；结合物理约束、BIC和残差改善顺序选阶 | 各阶模型、选中阶数、路径参数 |
| Stage 3 | Stage 2结果 | 在中心窗口前后各2个窗口中匹配附加路径，检查时延、多普勒和功率持续性 | 持续性表、可靠中心窗口 |
| Stage 4 | 可靠中心窗口 | 使用5个独立20 ms快照组成100 ms联合估计；共享路径时延/多普勒，各快照独立估计复幅度 | 联合模型阶数和最终路径表 |

“多窗口增加建模数据”有两种不同含义，不能混淆：

1. Stage 3 用邻窗检查同一条路径是否持续存在，主要用于排除随机噪声峰；
2. Stage 4 用5个20 ms快照联合估计公共路径几何参数，提升稳定性，但每个快照仍保留独立复幅度，以允许快衰落。

最终进入统计建模的应优先是 Stage 4 的可靠路径；Stage 2单窗结果只能作为诊断或在明确标记低置信度时使用。

## 7. 当前关键参数

| 参数 | 当前值 | 含义 |
|---|---:|---|
| 目标卫星 | G06 / PRN 6 / channel 4 | 当前单星验证对象 |
| 基本导航符号长度 | 20 ms | GPS L1 C/A NAV bit周期 |
| Stage 1/2窗口 | 40 ms | 含两个完整导航符号 |
| Stage 4联合长度 | 5×20 ms = 100 ms | 五快照联合估计 |
| 最大模型阶数 | `L=4` | 最多1主径+3附加多径 |
| 分数时延网格 | 0.1 sample = 0.01 chip | 时延细化分辨率 |
| 最小路径间隔 | 1 sample = 0.10 chip | 防止把同一相关峰重复拆分 |
| 最大附加时延 | 30 samples = 3 chips | 当前搜索上限 |
| 主径多普勒初搜范围 | 跟踪值±125 Hz | 围绕GNSS-SDR跟踪结果 |
| 地面车辆速度上限 | 120 km/h | 无可靠NMEA速度时使用 |
| 相对多普勒界限 | 基于车辆速度、L1波长和裕量动态计算 | 避免无物理意义的宽搜 |
| 最低 C/N0 | 30 dB-Hz | Stage 0质量门限 |
| 最弱附加路径 | 主径下方25 dB | 低于此值不作为有效路径 |
| 最大路径副本相干性 | 0.98 | 抑制不可分辨的重复路径 |
| 顺序选阶最低BIC增益 | 10 | 新增路径必须显著改善模型 |
| Stage 3邻窗范围 | 中心±2个40 ms窗口 | 共5个相邻窗口 |
| 最低连续匹配数 | 3 | 路径至少连续存在3窗 |
| Stage 4最低快照胜出数 | 4/5 | 高阶模型至少改善4个快照 |

这些门限是当前工程初值，不是最终统计模型参数。不得为了“必须检测出三径”而无依据地放松门限；如果没有可靠三径，应先检查信号、同步和模型失配，再做有记录的灵敏度分析。

## 9. 首次运行后的检查顺序

首次运行后，必须让用户提供：

1. 完整 MATLAB 控制台输出；
2. 整个 `sage_results\G06_nav_sage_v1` 压缩包。

接手 AI 应按以下顺序核验：

### 9.1 Stage 0

- 是否约为321个有效符号和319个完整40 ms窗口；
- 窗口是否只位于有直接导航位覆盖的时间段；
- 是否出现短读、采样边界或TOW不连续错误；
- C/N0、码频和跟踪多普勒是否有限且变化平滑。

若 Stage 0 不正确，不得继续解释 SAGE 结果。

### 9.2 Stage 1

- 自动选择的多普勒符号是否稳定；
- 导航位擦除后主相关峰是否显著；
- 残差峰是否集中在少量连续时段，而不是每窗随机跳动；
- 第二、第三残差峰是否具有合理的附加时延和相对多普勒。

### 9.3 Stage 2

- 统计 `selected_L=1,2,3,4` 的窗口数；
- 检查高阶模型是否同时通过BIC、RSS、功率、间隔、多普勒和相干性约束；
- 路径顺序是否按到达时延排序；
- `L=3/4` 是否只是单窗偶然结果。

### 9.4 Stage 3

- 检查每条附加路径是否至少连续匹配3个相邻窗口；
- 不应只看中心窗口的L；
- 如果 `stage3_reliable_centers.csv` 为空，Stage 4跳过是正常行为，不代表脚本错误。

### 9.5 Stage 4

- 联合模型是否在至少4/5快照上优于L=1；
- `joint_selected_L>=3` 才表示最终确认至少两条附加多径；
- 检查路径的附加距离、相对功率和相对多普勒是否符合地面车辆场景；
- 同一时段 Stage 2、Stage 3和Stage 4的路径数量与参数应大体一致。

## 10. 什么情况下可以宣称“检测到多径”

推荐证据等级：

| 等级 | 条件 | 可作出的结论 |
|---|---|---|
| 候选 | Stage 1残差出现独立峰 | 可能存在多径，不能定论 |
| 单窗估计 | Stage 2选中 `L>=2` | 该40 ms窗口支持多径假设 |
| 持续多径 | Stage 3路径跨至少3窗稳定 | 多径证据较强 |
| 可靠多径 | Stage 4联合估计保留该路径，且至少4/5快照改善 | 可进入统计建模样本库 |

如果 Stage 4 选择：

- `L=1`：未确认附加多径；
- `L=2`：确认1条附加多径；
- `L=3`：确认2条附加多径；
- `L=4`：确认3条附加多径。

研究目标希望找到三条及以上总路径，但不能把“找到L≥3”设成强制输出。真实场景若只支持L=1或L=2，应如实保留。

## 11. 如果 G06 没有得到可靠 L≥3，下一步怎么做

按以下顺序诊断，禁止直接降低BIC门限来制造路径：

1. 核对 telemetry 的导航符号与其采样起点是否对齐；
2. 核对跟踪多普勒符号、码频和原始IQ起始采样约定；
3. 观察导航位擦除前后主峰及残差能量是否合理；
4. 使用人工注入的已知双径/三径仿真验证脚本的检出能力和分辨界限；
5. 对高质量候选时段绘制更细的延迟-多普勒面和SAGE收敛曲线；
6. 对时延上限、路径间隔、窗口长度和功率阈值做有控制的灵敏度实验；
7. 检查本地码模型、接收机前端滤波、残余载波相位或动态码延迟是否造成模型失配；
8. 再选择其他低仰角合格卫星，如G28，重复同样的直接导航位流程。

若仿真能够检出三径而真实 G06 不能，结论应是该有效时段没有足够可靠的三径证据，而不是继续强行加阶。

## 12. G06完成后的多卫星扩展

当前脚本硬编码了 G06、PRN 6和channel 4。通过 G06 验证后，应编写通用版本，而不是复制七份脚本。

通用版本至少应增加：

1. 从配置、日志、tracking和telemetry自动建立 `PRN ↔ channel` 映射；
2. 与 RINEX NAV 的PRN集合求交，只处理合格卫星；
3. 每颗卫星独立建立完整导航符号窗口；
4. 每颗卫星独立自动判定多普勒符号并运行 Stage 1–4；
5. 将每个可靠100 ms结果按GPS TOW与仰角 timeseries 对齐；
6. 给每条样本写入 `scene_id`、`PRN`、`elevation_deg`、`elevation_bin`、时间和质量标志；
7. 输出统一的可靠路径长表，供后续统计建模。

建议的统一路径表至少包含：

## 13. 后续“场景×仰角”传统参数建模

可靠路径提取完成后，每个场景和仰角分区至少考虑以下统计量：

| 参数 | 建模意义 |
|---|---|
| 总路径数L或附加多径数 | 离散路径数量分布 |
| 附加时延/附加路程 | 反射路径几何尺度 |
| 相对功率 | 多径衰减强度 |
| 相对多普勒 | 散射体和车辆运动效应 |
| 路径持续时间/出生消失率 | 非平稳性 |
| RMS时延扩展 | 总体时域色散 |
| Doppler spread | 总体频域扩展 |
| 直达与散射功率比/K因子 | LOS强弱 |
| 参数间相关性 | 如时延-功率、仰角-路径数关系 |

不要先强制假定瑞利分布。推荐路线是：

1. 先画经验CDF、直方图、Q-Q图和参数关系图；
2. 根据物理量选择候选分布，例如指数、Gamma、对数正态、Weibull、Rayleigh、Rician、Nakagami；
3. 用最大似然估计参数；
4. 用AIC/BIC、KS/AD检验和留场景交叉验证比较模型；
5. 检查检测门限造成的截断/删失偏差；
6. 若单一经典分布不合适，使用混合分布、分段模型、经验CDF/KDE或层次模型；
7. 模型选择依据是拟合质量、跨采集场景泛化和物理可解释性，而不是只看某一个检验的p值。

样本量不足时，不应为每个小分区拟合过多参数。应报告样本数和置信区间，并考虑合并相邻仰角、采用bootstrap或层次模型。
